#+title: Panel Label CSS
#+date: 2026-06-19
#+phase: 2 (after 02)

Style ~.lox-panel-label~ and retarget row flex rules from ~.lox-panel~ to
~.lox-pane~.

* Background

Pane chrome uses ~border-radius: 20px~ on most panels (~static/css/lox-visualizer.css~
lines ~80–88~).  Labels should sit above the border box, right-aligned, with
~padding-right: 20px~ so the text's right edge aligns with the start of the
top-right corner curve — not flush with the row edge.

Depends on: ~.lox-pane~ / ~.lox-panel-label~ DOM from
[[file:02-pane-wrapper-dom.org][02-pane-wrapper-dom.org]].

* Acceptance

- Labels appear above every pane in the cloxvis post layout.
- Right edge of label text visually meets the pane's rounded corner (± a few px).
- Side-by-side panes (editor+lexer, bytecode+stack) each have their own label
  aligned to that pane's column.
- No regression to pane borders, AST svg sizing, or bytecode/stack row stretch.
