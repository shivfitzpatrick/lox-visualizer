#+title: Panel Labels — Overview
#+date: 2026-06-19

Add small descriptive labels to every compiler-viz pane.  Each label sits in the
*upper-right* corner, *above* the pane chrome, inset from the right edge to
line up with the pane's rounded border (currently ~border-radius: 20px~).

* Goal end-state

Every pane in a ~VisualizerLayout~ shows a human-readable label before its
content shell:

| Kind | Label |
|------+-------|
| ~editor~ | Source |
| ~lexer~ | Lexer |
| ~ast~ | Parser |
| ~bytecode~ | Bytecode |
| ~stack~ | Stack |
| ~console~ | Output |
| ~playback~ | Playback |

Labels are created automatically by ~buildLayoutDOM~ — no per-panel or per-post
markup.  Both the Lox and Python visualizers pick them up through the shared
mount path.

* Visual target

#+begin_example
                                    Lexer
                    ┌──────────────────────────────┐
  Source            │  token stream …              │
┌──────────────┐    └──────────────────────────────┘
│  print 1;    │
│              │
└──────────────┘
  [ Run ]

                                 Parser
                    ┌──────────────────────────────┐
                    │  (AST svg)                   │
                    └──────────────────────────────┘
#+end_example

- Label text is right-aligned above the pane, with ~padding-right~ matching the
  pane corner radius so the label's right edge visually meets the inner curve.
- Typography: small caps / uppercase, muted color (~#888~), mono stack — same
  family as the visualizer body.
- Labels are *not* interactive; they do not participate in selection or
  connectors.

* Out of scope (for now)

- Per-post or ~data-layout~ label overrides (English strings are fixed).
- i18n / localization.
- Renaming ~PanelKind~ values (~ast~ stays ~ast~; only the *display* label is
  "Parser").

* Design reference

Target DOM shape (settled in 02):

#+begin_example
.lox-visualizer
  .lox-visualizer-row
    .lox-pane
      .lox-panel-label     "Source"
      .lox-panel.lox-panel--editor   ← containers Map still points here
    .lox-pane
      .lox-panel-label     "Lexer"
      .lox-panel.lox-panel--lexer
#+end_example

Panel components continue to receive the inner ~.lox-panel~ shell as their
~container~ — no changes to ~LexerPanel~, ~AstPanel~, etc.
