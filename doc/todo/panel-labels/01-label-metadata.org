Define the canonical display string for each ~PanelKind~.  Pure TypeScript — no
DOM changes yet.

* Background

~PanelKind~ names are internal identifiers (~ast~, ~console~).  Labels shown to
the reader should use familiar compiler-pipeline vocabulary: "Parser" not "AST",
"Output" not "Console", "Source" not "Editor".

Centralizing strings in ~layout.ts~ keeps Lox, Python, tests, and future mobile
pane-switcher tabs in sync.

Add next to ~panelClass~ / ~panelShellId~:

#+begin_src typescript
export const PANEL_LABELS: Readonly<Record<PanelKind, string>> = {
    editor: 'Source',
    lexer: 'Lexer',
    ast: 'Parser',
    bytecode: 'Bytecode',
    stack: 'Stack',
    console: 'Output',
    playback: 'Playback',
};

export function panelLabel(kind: PanelKind): string {
    return PANEL_LABELS[kind];
}
#+end_src

Use ~Readonly<Record<…>>~ so every ~PanelKind~ must have an entry — the compiler
catches a missing label when a new kind is added.
