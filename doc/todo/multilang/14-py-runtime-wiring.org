Change ~run()~:

#+begin_src typescript
run(source?: string) {
    if (!this.pyCore) return;
    const text = source ?? this.getEditorText();
    this.selection.set({ selectedStart: null, selectedAstNode: null });

    const result = this.pyCore.run(text);
    if (!result.ok) {
        publishConsoleMessages(this.consoleStore, [{ type: 'error', text: result.error }]);
        this.dataStore.set({ data: null });
        return;
    }

    this.dataStore.set({ data: deriveVizData(result.data) });
    const consoleMsgs: ConsoleMessage[] = (result.data.console ?? []).map((m) =>
        m.type === 'print'
            ? { type: 'print' as const, text: m.text, srcOffset: m.src_offset }
            : { type: 'error' as const, text: m.text },
    );
    publishConsoleMessages(this.consoleStore, consoleMsgs);
}
#+end_src

** TODO Handle Python errors in the console panel
   :PROPERTIES:
   :files: app/src/python-visualizer/python-visualizer.ts
   :END:

~py-core.ts~ returns ~{ ok: false, error: string }~ for Python
~SyntaxError~, runtime exceptions, and Pyodide internal errors.  The ~run()~
method above already handles this by calling:

#+begin_src typescript
publishConsoleMessages(this.consoleStore, [{ type: 'error', text: result.error }]);
this.dataStore.set({ data: null });
#+end_src

Setting ~data: null~ clears the lexer/AST/bytecode panels (they check for
~null~ and render nothing).  The error message appears in the console panel in
red (~console-error~ class, already wired in ~ConsolePanel~).

Add a private helper to keep it concise:
#+begin_src typescript
private pushError(text: string) {
    publishConsoleMessages(this.consoleStore, [{ type: 'error', text }]);
}
#+end_src
