(~lox-visualizer/lox-visualizer.ts~) that builds to
~public/js/lox-visualizer/lox-visualizer.js~.  The Python visualizer needs the

~public/js/python-visualizer/python-visualizer.js~.

(~.language-python~) as the sample program anchor.
