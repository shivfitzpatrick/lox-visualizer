#+title: Phase 2c — Move Shell (Panel Base, Layout, Mount, Slots)
#+date: 2026-06-18
#+phase: 2c (after 04; parallel with 05)

Move the shared UI scaffolding — panel base class, layout types, DOM mount
logic, and the editor slot — from ~lox-visualizer/~ to ~compiler-viz/~.

Two targeted behavior changes land here:

1. ~buildLayoutDOM~ accepts a ~rootClass~ option (default ~'lox-visualizer'~) so
   a Python post can mount under a different CSS root without breaking the
   cloxvis post.
2. ~layout.ts~ sheds the hardwired Lox panel imports; ~createPanelRegistry~ is
   removed and replaced by the shared factory added in 08.

* Background

~visualization-panel.ts~, ~layout.ts~, ~mount.ts~, and
~slots/editor-slot.ts~ contain no Lox-specific rendering logic.  The only
coupling is:

- ~layout.ts~ imports the four Lox panel classes to wire ~createPanelRegistry~.
- ~mount.ts~ hardcodes the root CSS class ~lox-visualizer~.
- ~visualization-panel.ts~ imports types from ~lox-data.ts~ (fixed in 04).
