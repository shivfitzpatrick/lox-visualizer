* Background

These files contain no Lox-specific logic today:

| File | Notes |
|------+-------|
| ~connector-layer.ts~ | Anchor/line overlay, fully generic |
| ~ast.ts~ | d3 tree renderer; ~AstNode~ is already neutral |
| ~bytecode.ts~ | Table renderer; after 02 it consumes ~Instruction~, not ~CompilerEvent~ |
| ~theme.ts~ | Default palette; ~ColorScheme~ / ~TokenCategory~ from ~state/token.ts~ |
| ~d3-utils.ts~ | ~panelSelection~ / ~selectionNode~ helpers |

Moving them makes ~compiler-viz/~ self-contained; the ~lox-visualizer/~ stubs
become one-liner re-exports.
