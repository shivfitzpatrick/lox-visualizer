Five programs, each chosen to light up a different part of the
visualizer.  Constraints: standard Lox only (no ~%~ operator — it's
not in the book's grammar; verify anything fancier against *this*
clox before shipping), short enough that the AST stays readable and
the execution trace stays well under the MAX_STEPS cap.

* Proposed programs

** 1. Fibonacci — ~fibonacci.lox~

Shows: recursion, call-stack growth/shrink in the stack panel,
~OP_CALL~/~OP_RETURN~ in bytecode.

#+begin_src text
fun fib(n) {
  if (n < 2) return n;
  return fib(n - 1) + fib(n - 2);
}

for (var i = 0; i < 8; i = i + 1) {
  print fib(i);
}
#+end_src

Tune the loop bound down if the trace is too long in practice.

** 2. Closures — ~closures.lox~

Shows: upvalues, ~OP_CLOSURE~, a function outliving its scope.

#+begin_src text
fun makeCounter() {
  var count = 0;
  fun increment() {
    count = count + 1;
    return count;
  }
  return increment;
}

var counter = makeCounter();
print counter();
print counter();
print counter();
#+end_src

** 3. Classes & inheritance — ~inheritance.lox~

Shows: classes, ~init~, ~this~, ~super~, method dispatch.

#+begin_src text
class Animal {
  init(name) {
    this.name = name;
  }
  speak() {
    print this.name + " makes a sound.";
  }
}

class Dog < Animal {
  speak() {
    super.speak();
    print this.name + " barks!";
  }
}

var rex = Dog("Rex");
rex.speak();
#+end_src

** 4. Scopes & shadowing — ~scopes.lox~

Shows: block scoping, shadowing, locals living on the stack — a
classic "watch the slots" demo, and a nicely nested AST.

#+begin_src text
var a = "global";
{
  var a = "outer";
  {
    var a = "inner";
    print a;
  }
  print a;
}
print a;
#+end_src
