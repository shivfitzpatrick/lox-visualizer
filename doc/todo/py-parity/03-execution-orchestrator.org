#+begin_src typescript
const steps = result.data.steps ?? [];
const prints = result.data.prints ?? [];
this.executionStore.set({
    steps,
    prints,
    currentStep: steps.length > 0 ? 0 : null,
    playing: false,
});

When ~steps.length > 0~, do *not* push ~type:'print'~ to ~consoleStore~ — prints
flow through ~ExecutionStore~ and ~ConsolePanel~ playback mode.

When ~steps.length === 0~ (compile-only failure or no execution), keep current
fallback: all messages via ~consoleStore~.

Errors always go to ~consoleStore~.
