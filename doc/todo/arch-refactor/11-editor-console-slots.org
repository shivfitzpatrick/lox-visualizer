#+title: Editor and Console Slots
#+date: 2026-06-18
#+phase: 4b (after 09 — parallel with 10 and 12)

Extract the editor and console UI from the orchestrator into mountable
~Component~ slots that receive their pane shell from ~mountVisualizer~ (10).
Both participate in ~children~ lifecycle like ~VisualizationPanel~ but do *not*
subscribe to the selection store.

* Background

| Concern | Today (~lox-visualizer.ts~) | After |
|---------+----------------------------+-------|
| Editor | ~setUp~ lines ~137–158~: creates CodeMirror, Run button, replaces ~<pre>~ | ~EditorSlot~ fills ~.lox-panel--editor~ |
| Console | ~displayConsole~ + ~render~ / ~rerun~ rAF calls; queries ~#lox-console~ | ~ConsoleSlot~ renders into ~.lox-panel--console~ |
| Sample text | ~getText()~ reads editor or falls back to ~.language-nil~ | ~EditorSlot.getText()~; initial doc from ~MountResult.sampleCode~ |

The orchestrator keeps: WASM wiring, ~render()~ → ~dataStore.set~, ~rerun~
triggering ~lox.exports.runSource~.  It delegates display updates to slots.
