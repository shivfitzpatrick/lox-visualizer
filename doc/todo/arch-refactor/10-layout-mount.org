#+title: Layout Mount (DOM Builder)
#+date: 2026-06-18
#+phase: 4b (after 09 — parallel with 11 and 12)

Implement ~mountVisualizer~: given a sample-code anchor (~<pre>~ containing
~.language-nil~) and a ~VisualizerLayout~, build the ~.lox-visualizer~ DOM
tree, extract the sample source, and return ~MountResult~ (see 09).

* Background

Today ~setUp~ does two unrelated DOM surgeries:

1. Replace the ~<pre>~ with a ~.lox-editor-container~ (editor only).
2. Assume panel ~#lox-*~ divs already exist as post siblings.

After this task, *all* pane shells are created programmatically inside one root,
and the ~<pre>~ is replaced by that root (editor pane is empty until 11's
~EditorSlot~ fills it).

* Target mount flow

#+begin_example
Before (post):
  <pre><code class="language-nil">fun …</code></pre>
  <div id="lox-lexer">…</div>   ← author-maintained
  …

After mountVisualizer(pre, layout):
  <div class="lox-visualizer">
    <div class="lox-visualizer-row">
      <div class="lox-panel lox-panel--editor" id="lox-editor"></div>
      <div class="lox-panel lox-panel--lexer"  id="lox-lexer"></div>
    </div>
    <div class="lox-visualizer-row">
      <div class="lox-panel lox-panel--ast" id="lox-ast"></div>
    </div>
    …
  </div>
#+end_example

~sampleCode~ = text content of the code element (trim trailing newline once, same
as today's ~getText()~ fallback).

** DONE Implement ~buildLayoutDOM(layout)~
   :PROPERTIES:
   :files:    app/src/lox-visualizer/mount.ts
   :END:

- Create ~div.lox-visualizer~.
- For each non-empty row in ~layout~ (after ~validateLayout~):
  - append ~div.lox-visualizer-row~,
  - for each ~kind~ in the row, append a pane shell:
    - classes: ~lox-panel lox-panel--{kind}~,
    - optional ~id="lox-{kind}"~ using a fixed map (~bytecode~ → ~lox-compiler~
      to preserve the legacy id the bytecode CSS once targeted, or standardize
      on ~lox-bytecode~ — *pick one in this task and document in 12*).
- Return ~{ root, containers: Map<PanelKind, HTMLElement> }~.

Do *not* wire CodeMirror or D3 here — empty shells only.

** DONE Implement ~mountVisualizer(anchor, layout)~
   :PROPERTIES:
   :files:    app/src/lox-visualizer/mount.ts
   :END:

1. Resolve ~anchor~ (~<pre>~ or the code element — accept either).
2. Extract ~sampleCode~.
3. ~buildLayoutDOM(layout)~.
4. ~anchor.replaceWith(root)~ (replace the whole ~<pre>~, not just the code).
5. Return ~MountResult~.

If the post still contains legacy ~#lox-*~ sibling divs (during migration),
they are orphaned and harmless until 14 removes them.  Optionally log a dev
warning if ~#lox-lexer~ exists as a *sibling* of the replaced pre (author
forgot to clean the post).
