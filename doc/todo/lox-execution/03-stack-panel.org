Create =StackPanel=: a new visualization panel that renders the Lox VM stack for
the current playback step.  Slots are shown top-of-stack first, grouped by call
frame with separator lines and frame labels.

* Background

The stack panel is read-only.  It subscribes to =ExecutionStore= and re-renders
whenever =currentStep= changes.  It does not write to the store or participate
in the connector/selection system yet (see 06-polish for that follow-up).

Depends on: =ExecutionStore= and all types from 02.

import type { ExecutionStore, VmStep } from '@/compiler-viz/execution';

export class StackPanel {
    private store: ExecutionStore;

    constructor(container: HTMLElement, store: ExecutionStore) {
        this.container = container;

        this.store.subscribe(state => {
            if (state.currentStep === null) {
                this.renderEmpty();
            } else {
                this.renderStep(state.steps[state.currentStep]);
            }
        });
    }

Render the stack as a =<table>= using d3.  Slots display highest index (top of
stack) first so the most recently pushed value is at the top of the panel.

Structure:

#+begin_src html
<table class="stack-table">
  <tbody>
    <!-- one <tr> per slot, highest index first -->
    <tr class="stack-frame-label">
      <td colspan="3">myFn</td>
    </tr>
    <tr class="stack-slot">
      <td class="stack-idx">#5</td>
      <td class="stack-type">num</td>
      <td class="stack-val">3.14</td>
    </tr>
    <!-- frame boundary row -->
    <tr class="stack-frame-boundary"><td colspan="3"></td></tr>
    <tr class="stack-frame-label">
      <td colspan="3">script</td>
    </tr>
    <tr class="stack-slot"> ... </tr>
  </tbody>
</table>
#+end_src

Algorithm:

1. Build an array of display rows from =step.stack= and =step.frames=.
   - Walk =step.frames= in reverse (highest base last = innermost frame first in
     the reversed display).
   - Each slot belongs to the frame whose =base= is the highest base ≤ slot index.
2. For each frame boundary encountered while iterating slots top-to-bottom:
   - Insert a =stack-frame-boundary= row.
   - Insert a =stack-frame-label= row with the frame's function name.
3. Each slot row shows: =#{index}=, type badge (=step.stack[i].t=), formatted
   value.

Use d3 =.data()= / =.join()= so re-renders diff rather than rebuild.

* Open questions

- *Hide until first run*: should the stack panel be hidden with =display:none=
  until a run completes?  Probably yes — add a CSS class toggle on the
  container.  Simplest: check =steps.length > 0= in the store subscriber.
- *Slot 0 convention*: The design doc says "slot #0 = first pushed".  Confirm
  this matches how =vm.stack[0]= is used in clox (it is the reserved slot for the
  top-level script function in clox's implementation).
- *Frame label position*: the label row above works for display, but consider
  whether a sticky header per frame would help for tall stacks.  Defer to
  06-polish.
